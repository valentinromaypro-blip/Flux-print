# Site Carte Blanche

- `prototype/accueil.src.html` : maquette de la page d'accueil (les images sont insérées au moment de la publication).
- `public/img/` : visuels produits (rendus de nos propres cartes), en attendant les photos des jeux imprimés à l'atelier.
- `tools/generate_visuals.py` : génère ces visuels (cartes + mises en scène). Polices : paquets npm `@fontsource/bricolage-grotesque`, `@fontsource/hanken-grotesk`, `@fontsource/fraunces`.

Le site définitif (Next.js sur Cloudflare, branché sur Supabase) sera construit dans ce dossier.
